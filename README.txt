RoyalRise Elevators - website prototype

Open index.html in a browser (keep the images folder next to it).
Fonts load from Google Fonts and smooth scrolling from jsDelivr (Lenis 1.1.13);
both need internet. Without internet the page still works with system fonts
and normal scrolling.

Sections: hero scroll story, buildings + stats, solution cards, size calculator,
sticky technology section, horizontal design gallery, story, quote, dimensions
table, service, contact + FAQ, footer.

Contact form is a prototype: connect it to email/WhatsApp/backend before launch.
